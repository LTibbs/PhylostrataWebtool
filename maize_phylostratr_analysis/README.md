# Maize Phylostratr Analysis
This folder contains the scripts and input data files used to set up and run the phylostratr analysis of maize. The results of these analyses form the basis for the Maize Phylostrata Tool at https://phylostrata.maizegdb.org/. Run the following scripts in order:

1. [maize_phylostratr_setup.R](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/maize_phylostratr_setup.R):
This R script is used to set up for the phylostratr analysis.

2. [phylostratr_pipeline.sh](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/phylostratr_pipeline.sh):
This bash script is used to organize and submit the sub-scripts needed to actually run phylostratr.

3. [diamond_blast.sh](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/diamond_blast.sh)
This bash script is referenced by phylostratr_pipeline.sh above and is used to run Diamond Blastp for each query proteome against all other proteomes. This is used to speed up phylostratr's strata_blast().

4. [strata_blast_array.sh](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/strata_blast_array.sh)
This bash script is used to submit the phylostratr jobs as an array, here --array=1-48, where each represents a single proteome used as the query.

5. [strata_blast_array.R](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/strata_blast_array.R)
This R script is submitted by strata_blast_array.sh above, and runs the phylostratr analysis for each query proteome. 

## Example run
Calculate phylostrata levels for a test dataset of 7 B73 proteins:

Input data:
- [tree_filled_maize.Rdata](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/tree_filled_maize.Rdata): A pre-made phylostratr tree with maize as the focal species. This tree was be generated by [maize_phylostratr_setup.R](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/maize_phylostratr_setup.R) and contains 48 maize/PanAnd accessions, 57 other eukaryotes, and 116 prokaryotes. The proteomes referenced in this tree should be downloaded from [UniProt](https://ftp.uniprot.org/pub/databases/uniprot/current_release/knowledgebase/reference_proteomes/) and [MaizeGDB](https://download.maizegdb.org/) following the sections `Download UniProt proteomes` and `Add MaizeGDB proteomes` of [maize_phylostratr_setup.R](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/maize_phylostratr_setup.R).
-  [test_B73.faa](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/test_B73.faa): Fasta file containing protein sequence for the 7 example proteins. 
- [test_proteome.csv](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/test_proteome.csv): Use in place of [master_proteomes.csv](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/master_proteomes.csv) in order to run the small example rather than the full proteomes. [master_proteomes.csv](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/master_proteomes.csv) contains the information for the query proteomes from MaizeGDB and has 6 columns: assembly (assembly name from MaizeGDB), identifier (identifier from MaizeGDB), strata.name (a short name for the taxon, to be used for phylostratr output), haploid (whether this taxon is provided as two haploid genomes (T) or not (F)), annotation (which annotation project this proteome comes from (NAM, CAAS, PanAnd)), and group (for NAM only, whether the accession is tropical, temperate, mixed, sweet corn, or popcorn).

Output data: 
- [results.test_B73.3.Rdata](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/results.test_B73.3.Rdata): Rdata file of `results` R object. This data frame contains the top Blast hit in the subject proteomes (those in the phylostratr tree) for the example B73 query proteins. This data frame is output by the `merge_besthits()` function from phylostratr and can be processed to create the Gene Details pages.
- [phylostrata.test_B73.Rdata](https://github.com/LTibbs/PhylostrataWebtool/blob/main/maize_phylostratr_analysis/phylostrata.test_B73.Rdata): Rdata file of `phylostrata` R object. This data frame contains the assigned phylostratum for each query protein and can be processed to create the main phylostrata search results and visualizations.

The output files are then processed in [data_processing](https://github.com/LTibbs/PhylostrataWebtool/blob/main/data_processing/) to create the files for the webtool. Note that the phylostratum numbering (`ps`) in the example results files above is pre-processing (e.g., processing will combine all _Zea mays mays_ as "species-specific") and therefore differs from the final numbering used in the webtool.
